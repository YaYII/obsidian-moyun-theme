# 速查手册

## 一、调用样式类（cssclasses）

在笔记最上方的 frontmatter 里加 `cssclasses`，就能给这一篇套上专属排版。可以叠加：

```yaml
---
cssclasses:
  - my-govdoc
  - my-heading-numbers
---
```

### 排版模式类

| 类名 | 效果 | 适用 |
|---|---|---|
| `my-govdoc` | 公文格式：仿宋三号、首行缩进两字、标题黑体居中、全文不用彩色 | 党政机关公文（参照 GB/T 9704-2012） |
| `my-poetry` | 诗词：楷体/宋体、居中、行距 2.1、字距 0.06em | 诗词、对联、题记 |
| `my-thesis` | 论文：宋体正文、黑体标题、首行缩进、两端对齐 | 学术论文、正式报告 |
| `my-letter` | 信纸：正文下方有横线纹理，模拟稿纸 | 书信、日记 |
| `my-bigscreen` | 大字：整体放大 1.35 倍，行高 1.85 | 投影讲解、会议投屏 |
| `my-immersive` | 沉浸：淡化 `#`、`**` 等格式符号，鼠标悬停该行恢复 | 长文写作 |
| `my-vertical` | 中文竖排（需配合 `snippets/竖排诗文.css`） | 诗文、题跋 |

### 阅读增强类

| 类名 | 效果 |
|---|---|
| `my-indent` | 只给这一篇加首行缩进（不依赖全局开关） |
| `my-justify` | 只给这一篇开两端对齐 |
| `my-heading-numbers` | 标题自动编号（1. / 1.1 / 1.1.1） |
| `my-heading-underline` | H1/H2 加下划线装饰 |
| `my-emphasis-dot` | 用中文传统的着重号（句下圆点）替代强调色 |
| `my-compact-punct` | 用 `halt` 特性把全角标点压成半角，版面更紧凑 |

### 布局类

| 类名 | 效果 |
|---|---|
| `my-cards` | 文件列表 / 搜索结果卡片化 |
| `my-image-grid` | 连续图片自动转网格（配合 `my-grid-2` / `my-grid-3` / `my-grid-4` 指定列数） |
| `my-rainbow-folders` | 顶层文件夹彩色化 |
| `my-focus-mode` | 专注模式：淡化非当前段落 |

## 二、高亮颜色

默认 ==黄色高亮==；指定颜色用 HTML 写法：

```html
<mark class="my-hl-red">红色高亮</mark>
<mark class="my-hl-green">绿色高亮</mark>
<mark class="my-hl-blue">蓝色高亮</mark>
<mark class="my-hl-pink">粉色高亮</mark>
<mark class="my-hl-purple">紫色高亮</mark>
<mark class="my-hl-gray">灰色高亮</mark>
```

效果：<mark class="my-hl-red">红色</mark> <mark class="my-hl-green">绿色</mark> <mark class="my-hl-blue">蓝色</mark> <mark class="my-hl-pink">粉色</mark> <mark class="my-hl-purple">紫色</mark> <mark class="my-hl-gray">灰色</mark>

## 三、标注（Callout）

写法：`> [!类型] 标题`，加 `-` 默认折叠、加 `+` 默认展开。

> [!note] note ／ 说明
> 中性信息。

> [!abstract] abstract ／ summary ／ tldr ／ 摘要
> 内容摘要。

> [!info] info ／ 信息
> 补充信息。

> [!todo] todo ／ 待办
> 待处理事项。

> [!tip] tip ／ hint ／ 技巧
> 实用建议。

> [!success] success ／ check ／ done ／ 成功
> 成功结果。

> [!question] question ／ help ／ faq ／ 疑问
> 待解决的问题。

> [!warning] warning ／ caution ／ attention ／ 注意
> 需要留意的风险。

> [!failure] failure ／ fail ／ missing ／ 失败
> 失败结果。

> [!danger] danger ／ error ／ 危险
> 严重问题。

> [!bug] bug ／ 缺陷
> 已知缺陷。

> [!example] example ／ 示例
> 示例内容。

> [!quote] quote ／ cite ／ 引用
> 引述内容。

嵌套标注会有缩进与色条区分：

> [!note] 外层
> 外层内容。
>
> > [!tip] 内层
> > 内层内容，左侧色条会再缩进一级。

## 四、八大韵色

在 Style Settings → 墨韵 MoYun → 🎨 配色 → 主题色（八韵）里切换。

| 韵色 | 色调 | 适用场景 |
|---|---|---|
| **青花** | 清透钴蓝 | 默认。通用写作、技术笔记，冷静不抢眼 |
| **朱砂** | 中国红 | 重点标记、批注、需要醒目提示的库 |
| **竹青** | 竹叶绿 | 生活记录、自然主题 |
| **藤紫** | 紫藤 | 创意写作、灵感笔记，柔和偏冷 |
| **秋香** | 橄榄黄绿 | 沉稳古典，历史、文献、读书笔记 |
| **黛青** | 深青绿 | 严肃文档、法律、财务 |
| **胭脂** | 胭脂粉 | 柔和的暖调粉，日记、情感类笔记 |
| **松烟** | 水墨灰 | 近乎无彩的极简形态 |

换色会同时作用于：链接、标签底色、主按钮、开关开启态、滑块、当前选中文件、标签页高亮、设置项选中态、有序列表编号、选中文本背景、输入框聚焦描边、关系图谱高亮节点、Canvas 选中框。

### 自定义颜色（进阶）

写一个 CSS 片段即可整体换色：

```css
body {
  --my-accent-custom: #7a5c3e;
}
```

> [!note] 关于自定义色的边界
> `--my-accent-custom` 会接管 `--my-accent` 及其派生色。但 Obsidian 内部少数位置使用的是
> `--color-accent-hsl` 这种三元组形式，自定义色在那些位置可能仍显示为八韵的颜色。
> 这些位置可见范围很小，若在意请直接选一个接近的韵色。
