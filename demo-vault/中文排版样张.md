# 中文排版样张

这份笔记用来**验收**主题的排版决策。每一节都说明「为什么这么做」，你可以逐条判断是否同意。

## 一、中西文自动间距

这段文字里混排了 English words 与数字 12345，还有标点（括号）。如果中西文之间自动产生了约八分之一全角的间隙，说明 `text-autospace` 生效了。

这是 Chromium 原生能力（CSS Text Level 4），**不需要任何 JS 插件**，也不会往你的 .md 文件里插入空格。

> [!note] 为什么不用 pangu.js
> 社区常用的 pangu.js 会插入**真实空格字符**，污染原文、Git diff 与全文搜索；
> `text-autospace` 是排版级间距，复制时不会带出空格，视觉等效且零污染。

## 二、行高与段距

中文汉字的方块密度远高于拉丁字母，同样字号下需要更大的行高才能获得同等阅读速度。业界经验值约为 1.7～1.9 倍字号，本主题默认取 1.8，可在 Style Settings 中调整。

段落之间留出约 0.85em 的间距。若你在 Style Settings 里打开「首行缩进两字」，建议同时把段距调小 —— 两种段落分隔方式叠用会显得松散。

## 三、标题层级

中文标题若使用 700 以上的字重，笔画会互相粘连，小字号下尤其明显。因此本主题把标题字重统一在 **650**，并借助上下留白而非粗细来建立层级。

## 五、引用

> 善用兵者，屈人之兵而非战也。
>
> ——《孙子兵法·谋攻》

引用块用左侧色条标示而**不加斜体** —— 中文没有真斜体，浏览器强行倾斜会让字形失真。需要强调时，主题默认用「变色 + 半粗」，也可以在 Style Settings 里改成中文传统的**着重号**。

## 六、表格

| 属性 | 9 个主流开源主题中的命中率 | 说明 |
|---|---|---|
| CJK 字体族名 | 1 / 9 | 仅 Blue Topaz 配置了中文字体栈 |
| `text-autospace` | 0 / 9 | 中西文间距完全缺失 |
| `text-spacing-trim` | 0 / 9 | 标点挤压缺失 |
| `text-indent` 首行缩进 | 1 / 9 | 且需手动加 cssclasses |
| `line-break` 避头尾 | 0 / 9 | 未声明（Chromium 默认已强制，影响有限） |

中文表格的单元格内边距比英文主题更大，因为汉字在过窄的格子里会显得挤压。

## 七、代码

行内代码如 `text-autospace: normal;`，以及带中文注释的代码块：

```css
/* 中文注释在代码块中同样应当清晰可读 */
.markdown-rendered {
  text-autospace: normal;         /* 中西文自动间距 */
  text-spacing-trim: space-first; /* 标点挤压（当前中文字体多无 chws 特性，实际可能不生效） */
  line-break: strict;             /* 避头尾（Chromium 默认已强制，此处为防御性声明） */
}
```

## 十、标注

> [!tip] 提示
> 标注的完整类型清单与配色见 [[速查手册]]。

> [!warning] 一个诚实的说明
> 「标点挤压」（`text-spacing-trim`）在思源黑体 / Noto Sans CJK 上**实际不生效** ——
> 该属性依赖字体的 `chws` 特性，而这些字体只提供 `halt` / `palt`。
> 主题保留了这行声明（字体将来具备 `chws` 时可自动受益），并在设置里提供了基于
> `halt` 的「紧凑标点」开关作为替代方案。
