# 代码片段（Snippets）说明

这里的 `.css` 文件是**可选增强**，不属于主题本体。用法：

1. 把需要的文件复制到你的库：`<你的库>/.obsidian/snippets/`
2. 打开 Obsidian → 设置 → 外观 → 拉到最底部「CSS 代码片段」→ 点击刷新按钮
3. 打开对应片段的开关

## 为什么放在片段里而不是主题里

主题的每一项样式都会作用到**所有**笔记。片段是「这个库/这类笔记才需要」的东西，
放片段里可以让主题保持克制，同时不牺牲可定制性。判断标准很简单：

- 会不会改变正文的**基本阅读体验**？会 → 放主题（要慎重）
- 只有某些场景才需要？→ 放片段

## 片段清单

| 文件 | 用途 | 注意 |
|---|---|---|
| `竖排诗文.css` | 中文竖排（`writing-mode: vertical-rl`），配合 `cssclasses: my-vertical` | 仅阅读视图与导出 PDF 可靠；实时预览下的光标定位可能异常 |
| `打印与导出优化.css` | 导出 PDF / 打印时去掉底色、加页边距、标题不与正文分页 | 全局生效，仅影响打印媒体 |
| `紧凑标点.css` | 用 `halt` 特性把全角标点压成半角，版面立刻紧凑 | 标点形态会变窄，属风格选择 |
| `中文排版增强.css` | 调研阶段沉淀的独立排版方案（可单独用于其它主题） | 与主题的排版核心功能有重叠，不需要同时启用 |

## 自己写覆盖样式

想改主题的某个细节又不想改源码时，新建一个片段直接覆盖即可。
主题的令牌体系让这件事很容易——改令牌比改组件选择器稳得多：

```css
/* 例：把正文行宽收窄到 40rem，行高放宽到 2.0 */
body {
  --my-content-width: 40rem;
  --my-line-height-relaxed: 2.0;
}

/* 例：整体换成自定义强调色（会同时影响链接、标签、按钮、选中态） */
body { --my-accent-custom: #7a5c3e; }

/* 例：只改阅读视图里的引用块底色 */
.markdown-rendered blockquote {
  background-color: color-mix(in oklab, var(--my-accent) 8%, transparent);
}
```

可用的令牌清单见 `docs/dev/token-contract.md`。
